ARCA Colonial Image Classifier | software development


Is a web tool for automatically cataloging colonial Latin American paintings and prints (16th–19th centuries) according to the iconographic scheme of the ARCA project. Users drag artwork images into the interface, and the app sends them to Claude's (Anthropic) vision model, which analyzes each piece and returns a structured classification: iconographic category, symbols, descriptors, characters, gestures, scene composition, and a descriptive synthesis, across more than 25 fields. Every suggestion stays editable on screen so a human reviewer can correct anything needed, and the final data is exported to a CSV compatible with the project's existing database of ~27,000 records.

Technically, it's a pure HTML/JS single-page app (no backend, no build step): the browser resizes and compresses each image, sends it along with a reference system prompt to the Claude API using tool use to force a structured JSON response, and renders the result as an editable card. The reference prompt embeds the project's real controlled vocabularies (symbols, descriptors, category tree, characters, gestures) so the model reuses categories already present in the historical database instead of inventing new variants — the key design challenge was translating a complex curatorial cataloging scheme into a data contract a language model can fill out consistently, image after image.

The biggest challenge was context volume: the reference vocabulary is large enough that each individual classification consumes tens of thousands of input tokens, which directly affects response time and cost per image. To mitigate this, the app relies on Anthropic's prompt caching (the reference block is cached across calls) and a retry pipeline with backoff to tolerate transient network errors or rate limits — decisions aimed at making the project usable on batches of hundreds of images without constant manual intervention.
