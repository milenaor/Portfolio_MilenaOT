ARCA Colonial Viewer | Web/mobile interface development


I developed a search and exploration tool for heritage collections, designed to query artworks using multiple criteria such as location, date, author, classification, techniques, symbols, characters, and other semantic attributes. The interface combines hierarchical filters with free-text search, allowing users to refine results quickly and explore the collection from different perspectives without losing context or detail.

The tool connects to a structured database, loads references and metadata in real time, and generates a dynamic catalog with thumbnails, statistics, and visualizations by category, country, and decade. In addition, each work can be opened in a detailed view with contextual information, facilitating comparison between pieces and the identification of patterns within the collection.

This project integrates user experience design, data analysis, and query optimization to provide fast access to large volumes of information. From a professional perspective, it reflects strong capabilities in database management, interactive interfaces, advanced filtering, data visualization, and the development of tools oriented toward research, cultural management, and data-driven decision-making.
